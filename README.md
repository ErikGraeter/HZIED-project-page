# HZIED — interactive research homepage

An interactive, animated homepage for the **Habitable Zone Inner Edge
Discontinuity (HZIED)**: rocky planets beyond the runaway greenhouse limit
lose their oceans to an extended steam atmosphere and appear larger in
transit; across a population this produces a step in mean planet radius at
the inner edge of the habitable zone, which a Bayesian model comparison can
detect.

The hero section is a continuously looping, synchronised animation:

| Left — 3D planet (three.js, custom GLSL) | Right — radius vs. absorbed flux (Canvas) |
|---|---|
| A rocky planet rotates; the hot side features only planets that inflate (the non-inflating hot planets remain in the plot and in the evidence as open rings; they are featured only if no planet has an envelope, e.g. f_rgh = 0). For these planets the oceans evaporate, the surface heats and a steam envelope grows from the rocky radius to the model transit radius (rings mark both; the envelope is drawn ×3 thicker by default and labelled as such). On the cold side, a small and a large planet are followed by a line-up of five cold planets spanning the radius distribution, drawn to scale. | A ghost marker tracks the planet's radius as it inflates; the planet then flies into its point. The hot side fills with points (inflation stems), the threshold draws in, the cold side fills, binned means reveal the step. Then 50 red posterior draws of the step model (free threshold) converge as the survey grows, and the best fit is selected. The H0 line (dashed) and the draws are identified by the legend; only the best fit carries a direct label. |

Everything is driven by one clock and one pure scene function
(`src/timeline/storyboard.ts → sceneAt(t)`), so the sequence can be paused,
scrubbed, replayed and looped seamlessly.

## Launching

**No installation (any computer with a modern browser):**
double-click **`HZIED Homepage.html`**. It is a single self-contained file
(JavaScript, data and fonts inlined) and opens directly from disk.

**Live development server (macOS):** double-click **`launch.command`**, or in a
terminal:

```bash
npm run dev          # http://127.0.0.1:5173 (opens the browser)
```

Other commands:

```bash
npm run build        # multi-file build → dist/   (serve with: npm run preview)
npm run build:single # single-file build → dist-single/index.html and "HZIED Homepage.html"
npm test             # model tests (vitest)
npm run typecheck
```

Requirements: a WebGL2-capable browser (Chrome, Edge, Firefox, Safari 15+).
Building requires Node.js ≥ 20. `node_modules/` is already installed in this
folder; if it is missing, `launch.command` installs it with a local cache
(`./.npm-cache`).

### URL parameters

| Parameter | Effect |
|---|---|
| `?t=<seconds>` | start at a given time of the loop |
| `&paused=1` | start paused |
| `&speed=<x>` | playback speed |
| `&mode=explore` | open in explore mode |
| `&sample=artificial` / `plato` | choose the planet population |
| `&still=1` | skip the intro fade (for reproducible screenshots) |

### Interaction

* Play/pause (Space), replay (R), timeline scrubbing, speed 0.5×–2×.
* **Cinematic / Explore** toggle. In Explore mode, hover a point for its
  properties and click it to bring that planet into the 3D view; the card's
  *Replay transition* button re-runs its runaway-greenhouse transition.
* Drag the planet to rotate it.
* **Science controls** re-run the model in the browser: planet population
  (Artificial population / PLATO targets), runaway threshold S_thresh,
  water-to-rock ratio (wrr), inflated fraction f_rgh, number of observed
  planets N, PLATO-like radius noise, and a purely visual exaggeration of the
  envelope thickness (default ×3; ×1 = model radius).
* `prefers-reduced-motion` starts paused on the complete figure.

### The toy Bayesian comparison

Computed from exactly the planets shown (`src/model/evidence.ts`):

* H0: R_i ~ N(μ, σ²) for all planets
* H1: R_i ~ N(μ_hot, σ²) if S_abs > S_thresh, else N(μ_cold, σ²), with the
  threshold **free**
* priors: μ, μ_hot, μ_cold ~ U(0.5, 3) R⊕; σ ~ log-uniform(0.02, 2) R⊕;
  S_thresh ~ U(10, 1000) W m⁻² (the bounds of the pipeline's H1)

The means are integrated analytically, σ numerically, and S_thresh exactly (the
likelihood only changes when the threshold crosses a planet, so the integral
is a sum over the intervals between sorted fluxes; a unit test checks it
against brute-force integration). ln ΔZ = ln Z_H1 − ln Z_H0 is therefore exact
for this model. The 50 red lines are draws from the same posterior — as the
50 posterior draws in the thesis Fig. 5 (`plot_fig5`, `n_draws=50`) — sampled
with fixed random numbers so they evolve smoothly as the survey grows; the
selected **best fit** is the posterior-median threshold with the side means
of that split. The thesis itself fits the Schlecker et al. (2024) step model
with nested sampling (dynesty), whose evidence values differ.

At the fiducial setting: Artificial population (1786 planets) ln ΔZ ≈ +20.8,
best-fit S_thresh ≈ 253 W m⁻² (68 %: 221–280); PLATO targets (211 planets)
ln ΔZ ≈ −1.1, threshold unconstrained (90–400 W m⁻²). Null test f_rgh = 0 on
the Artificial population: ln ΔZ ≈ −2.0.

## RV follow-up section (scroll below “Testing with PLATO”)

A continuous story — ground-based telescope → stellar wobble → RV measurement →
planetary mass → normalized density → HZIED detection significance:

1. **RV explainer** (animated): a P5 planet and its star orbit the barycentre;
   the star's line-of-sight velocity Doppler-shifts its spectrum as recorded by
   ESPRESSO at ESO's VLT. A measurement campaign of N_RV epochs plays out: each
   exposure adds one velocity (true value + N(0, σ_RV)) at the orbital phase of
   that moment, folded on the period known from the transits; phase-binned
   means (±σ_RV/√n) show the sinusoid emerging from the noise; the
   semi-amplitude is fitted live by linear least squares with the phase fixed
   (σ_K̂ = σ_RV/√Σcos²φ → √(2/N_RV) σ_RV), and the implied mass M̂ ± σ_M is
   shown on a gauge against the true mass. A signal-vs-noise bar compares K
   with σ_RV on the plot's velocity scale. Two example planets from the
   predicted sample: the median-K planet and the largest-K planet. The
   campaign is the representative one of 31 seeded campaigns (median of the
   largest standardized deviation |K̂ − K|/σ_K̂ along the run). K, σ_K and σ_M/M
   are exact for the chosen planet (sliders); wobble and line shifts are
   exaggerated.
2. **Normalized density** (five-step morph): P5 planets in mass–radius space →
   orthogonal projection onto a Zeng+2016 rocky relation
   (`mr_reference.project_onto_curve`) → ρ_norm = ρ/ρ_ref → ρ_norm versus
   absorbed flux with the 280 W m⁻² threshold → measured values with error bars.
3. **Scenarios**: optimistic σ_M/M = 10 % (constant) or pessimistic σ_M/M ≈ σ_K/K
   with σ_K = √(2/N_RV) σ_RV and K from each planet's mass, period and stellar
   mass (`pipeline._rv_sigma_M_frac`); defaults σ_RV = 1 m/s, N_RV = 100, e = 0.
   All adjustable. σ_R/R = 3 % (P5).
4. **Detection significance vs. number of planets**: one-sided Welch t-test of
   ρ_norm, cold > hot, at 280 W m⁻² (`magma_ocean_ttest`), converted to Gaussian
   σ; median and 16–84 % of 150 realizations per point; null test without steam
   inflation for reference; 2σ/3σ lines; N slider linked to the density plot.

**Reference relation.** The default is the Zeng+2016 pure-rock (MgSiO₃)
relation — the rocky baseline the Bioverse generator assigns to the planets — so
a bare rocky planet has ρ_norm ≈ 1 (1.004 ± 0.002) and the steam-inflated hot
side drops to ≈ 0.86. Earth-like (32.5 % Fe) and a 20 % Fe mix are selectable;
with the Earth-like relation every planet is offset to ≈ 0.82, which is also
what the pipeline's default `reference_composition='earthlike'` produces for
these populations. The detection significance hardly depends on the choice.

Uncertainties are propagated by Monte Carlo with **repeated projections**: each
draw measures M_obs = M(1 + σ_M/M z) (clipped at 0.5 M⊕, dropped above 5 M⊕ as in
`_apply_mass_noise`) and R_obs = R(1 + σ_R/R z), and projects the *measured* point
onto the relation, so ρ_norm = ρ_obs / ρ_ref(M_obs, R_obs). This differs from the
pipeline's density branch, which draws ρ_obs ~ N(ρ_true, σ_ρ) and divides by
ρ_ref(M_true, R_true).

Population: 11 independent Bioverse realizations of P5 (seeds 8, 13, 42,
100–107; 5-yr mission, 0.5–5 M⊕, depth ≥ 60 ppm as in the WP2 density studies),
977 planets. Seed 8 (79 planets: 64 hot / 15 cold) is the predicted sample;
larger N draws from the pooled realizations and is marked as a forecast.
Seeds 100–107 were generated with `pipeline._generate_population` for this
section (the exporter regenerates them in memory if their parquets are absent).

Result at the defaults (MgSiO₃ reference): optimistic follow-up reaches a
median 3σ at N ≈ 100 (2.6σ at N = 79, P(≥3σ) = 33 %); pessimistic follow-up
(median σ_M/M ≈ 59 %) needs N ≈ 660 (2σ at N ≈ 300). Without measurement
errors the predicted sample shows the step at 9.8σ. The null test stays at
≈ 0σ.

## Data: regenerating the export

The website reads `src/data/hzied_data.json` (bundled at build time). It is
produced by `scripts/export_hzied_data.py`, which imports the HZIED repository
read-only and calls the pipeline's own `_reapply_inflation` and
`_observable_cuts`; nothing is written into the repository.

```bash
# in the HZIED conda environment (needs numpy, pandas, scipy, dynesty, bioverse deps)
python3 scripts/export_hzied_data.py --repo <path-to-HZIED-repository> \
    [--catalogs-dir <extra directory with raw population parquets>]
npm run build:single
```

Raw populations used (looked up in `<repo>/outputs/catalogs/` and any
`--catalogs-dir`; generated in memory with the Bioverse Generator if absent):

| Population on the site | Pipeline sample · raw parquet | Cuts | Observable planets (fiducial) |
|---|---|---|---|
| Artificial population (nearby stars, Schlecker+2024 setup) | `generic` · `population_fiducial_raw_seed8.parquet` | 0.5–5 M⊕, depth ≥ 80 ppm | 1786 (1152 hot / 634 cold) |
| PLATO targets (P4 + P5, optimistic) | `P5` + `P4` · `population_plato_P5_raw_dur5.0yr_seed8.parquet`, `population_plato_P4_raw_dur5.0yr_seed8.parquet` | 5-yr mission, 0.5–20 M⊕, depth ≥ 60 ppm | 211 (178 hot / 33 cold) |

For the PLATO targets each component keeps the pipeline's own seeded
inflation draws (as in a multi-sample P4+P5 run) and its radius precision
(P5 3 %, P4 4 %). The 20 M⊕ upper limit is the certified range of the
AGNI+PALEOS steam table.

Checks performed on export: the per-planet uniform draws reproduce the
pipeline's `has_magmaocean` for every component; with the P5 cuts of the
first export (0.5–5 M⊕, 80 ppm) the result was identical to the pipeline's cached
`population_plato_P5_thresh280_agni_updated_wrr0.0050_frgh0.80_M0.5-5_dur5.0yr_seed8.parquet`;
regenerating the Artificial population's raw parquet with the Generator reproduces the
cached one exactly (M, R_orig, S_abs, R_st, P, transiting compared). `src/data/hzied_validation.json` holds the pipeline radii
used by the unit tests. If the export is missing, the site falls back to
clearly labelled synthetic data (`src/data/synthetic.ts`).

## Architecture

```
src/
  model/      types, seeded RNG, inflation port + cuts, toy evidence, featured-planet choice,
              rv.ts (projection, RV precision, Welch test, Monte Carlo significance)
  timeline/   storyboard (shots, point timings, phases) and the playback clock
  three/      PlanetView (scene, rigs, flights), GLSL materials (surface, clouds,
              ray-marched atmosphere), deterministic planet looks
  plot/       PlotView — canvas renderer and hit-testing for the radius–flux plot
  ui/         Hero (single animation loop), science panel, sections, charts, starfield
  ui/rv/      RV follow-up section: RV animation, density morph, significance chart
  data/       pipeline export (JSON) and synthetic fallback
scripts/      export_hzied_data.py
tests/        model.test.ts — pipeline reproduction, exact evidence, posterior fit, line-up, seamless loop
              rv.test.ts    — projection, σ_M/M, ρ_norm and Welch test against the pipeline / scipy
```

The steam envelope is a ray-marched exponential atmosphere whose extinction is
normalised so that the tangential optical depth equals 1 at the model transit
radius — the transit radius is where a grazing ray becomes opaque. Below the
cloud deck the haze density saturates so the rocky interior (and, on the night
side, magma glow) remains faintly visible. The rocky radius and the transit
radius are independent uniforms; surface rotation is independent of inflation.
